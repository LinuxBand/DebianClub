패키지 이름이나 키워드를 입력하면 [pkgseek](https://pkgseek.com/)이 수집한 25개 이상 배포판의 공식 저장소를 실시간으로 검색할 수 있습니다.

<PackageSearch lang="en" />

## 사용 안내

- 결과에서 **Debian 13 (trixie)** 버전이 강조 표시됩니다. 패키지 이름을 클릭하면 pkgseek 패키지 페이지에서 전체 배포판 버전, 의존성, 관련 CVE를 확인할 수 있습니다.
- 검색 공유: 검색 후 주소창에 `?q=<키워드>`가 표시되므로 링크를 복사해 공유하세요.
- 기타 온라인 도구: [오류 → 설치 명령](https://pkgseek.com/doctor), [파일 역조회](https://pkgseek.com/files), [버전 매트릭스 임베드](https://pkgseek.com/embed/packages/nginx).
- 로컬 패키지 관리는 [APT 가이드](/ko/administration/packages)를 참고하세요.
