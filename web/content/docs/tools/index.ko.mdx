이 도구들은 브라우저에서 로컬로 실행됩니다. 인터랙티브 UI는 현재 영어로 제공되며, 이 페이지는 한국어로 사용 범위를 정리합니다.

<InteractiveTools lang="en" />

## 범위

- 선택 내용은 업로드되지 않습니다.
- 출력은 추천이며 시스템을 자동으로 변경하지 않습니다.
- 명령을 복사하기 전에 릴리스 코드명, 미러, 컴포넌트, 디스크 상태, 현재 환경을 확인하세요.

## 도구

| 도구 | 목적 |
|------|------|
| Mirror Selector | deb822 APT 소스 권장안을 생성 |
| Install Planner | 장치, 목표, 위험 선호도에 따라 설치 경로 선택 |
| Desktop Picker | 하드웨어와 작업 흐름에 맞춰 GNOME, KDE Plasma, Xfce 추천 |
| Partition Planner | 디스크, 부팅 모드, 암호화 설정에 따른 파티션안 제안 |
| Troubleshooting Wizard | 읽기 전용 점검 명령과 진단 경로 제공 |
| Command Safety Checker | 원격 스크립트, 재귀 삭제, 디스크 쓰기, SSH 보안 저하, APT 신뢰 위험을 로컬에서 표시 |
| AI Skills Installer | DebianClub AI Skills 로컬 설치와 검증 명령 생성 |
