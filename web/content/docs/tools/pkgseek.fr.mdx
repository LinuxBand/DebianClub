## Notes d'utilisation

- Les résultats mettent en avant la version **Debian 13 (trixie)** ; cliquez sur le nom du paquet pour ouvrir sa page pkgseek avec toutes les versions, dépendances et CVE.
- Recherches partageables : après la recherche, la barre d'adresse affiche `?q=<mot-clé>` — copiez le lien pour partager.
- Autres outils en ligne : [Erreur → commande d'installation](https://pkgseek.com/doctor), [recherche inversée de fichiers](https://pkgseek.com/files), [matrices de versions intégrées](https://pkgseek.com/embed/packages/nginx).
- Gestion locale des paquets : [guide APT](/fr/administration/packages).
