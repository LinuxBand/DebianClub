Debian Interactive Tools turn common decisions and troubleshooting paths into clickable tools, helping you reach the right installation, configuration, or diagnostic guide faster.

<InteractiveTools lang="en" />

## Boundaries

- The tools run locally in your browser and do not upload selections.
- Outputs are recommendations and never modify your system automatically.
- Before copying commands, verify the release codename, mirror, components, disk state, and current system environment.
- Use URL hashes to open a specific tool directly, for example `/en/tools#command-safety`; the command safety checker can also copy share links with the `command=` prefill kept inside the URL fragment.

## Live Tools

| Tool | Purpose |
|------|---------|
| Mirror Selector | Generate deb822 sources recommendations and link to the source format guide |
| Install Planner | Recommend an installation path based on device, goal, and risk preference |
| Desktop Picker | Recommend GNOME, KDE Plasma, or Xfce based on hardware and workflow |
| Partition Planner | Suggest partition layouts based on disk size, boot mode, and encryption preference |
| Troubleshooting Wizard | Provide read-only checks and route to the matching troubleshooting page |
| Command Safety Checker | Locally flag remote scripts, recursive deletion, disk writes, SSH downgrades, and APT trust risks |
| AI Skills Installer | Generate DebianClub AI Skills local install and validation commands |
