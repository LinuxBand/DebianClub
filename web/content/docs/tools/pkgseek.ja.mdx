パッケージ名やキーワードを入力すると、[pkgseek](https://pkgseek.com/) が収録する 25+ ディストリビューションの公式リポジトリをリアルタイム検索できます。

<PackageSearch lang="en" />

## 使い方

- 結果では **Debian 13 (trixie)** のバージョンが強調表示されます。パッケージ名をクリックすると pkgseek のパッケージページで全ディストリビューションのバージョン、依存関係、関連 CVE を確認できます。
- 検索の共有：検索後、アドレスバーに `?q=<キーワード>` が表示されるので、リンクをコピーするだけで共有できます。
- その他のオンラインツール：[エラー → インストールコマンド](https://pkgseek.com/doctor)、[ファイル逆引き](https://pkgseek.com/files)、[バージョンマトリックス埋め込み](https://pkgseek.com/embed/packages/nginx)。
- ローカルのパッケージ管理は [APT ガイド](/ja/administration/packages) を参照してください。
