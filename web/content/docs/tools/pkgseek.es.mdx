## Notas de uso

- Los resultados destacan la versión de **Debian 13 (trixie)**; pulse el nombre del paquete para abrir su página en pkgseek con todas las versiones, dependencias y CVE.
- Búsquedas compartibles: tras buscar, la barra de direcciones muestra `?q=<palabra>` — copie el enlace para compartir.
- Más herramientas en línea: [Error → comando de instalación](https://pkgseek.com/doctor), [búsqueda inversa de archivos](https://pkgseek.com/files), [matrices de versiones incrustadas](https://pkgseek.com/embed/packages/nginx).
- Gestión local de paquetes: [guía de APT](/es/administration/packages).
