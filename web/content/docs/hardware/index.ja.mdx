## 診断の原則

1. 先にデバイス ID とカーネルモジュールを確認します。
2. 不明なスクリプトより Debian リポジトリと backports を優先します。
3. firmware、カーネル、ドライバー、デスクトップセッションを同時に変えません。
4. 変更前後の出力を残します。
5. TTY や有線 LAN などの復旧経路を残します。

## よく使うコマンド

```bash
lspci -nnk
lsusb
uname -a
journalctl -b -p warning
dmesg --level=err,warn
```
