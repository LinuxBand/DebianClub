Debian 按惯例以《玩具总动员》角色为版本命名，约每两年发布一个稳定版。本页把近几代版本的发布时间线、支持窗口和升级路线放在一起，帮你判断"该在哪、往哪走"。

| **Debian 13** | Trixie | **2025-08-09** | 6.12 LTS | **当前 stable** ✓ |
| Debian 12 | Bookworm | 2023-06-10 | 6.1 LTS | [LTS 至 2028-06-30](/debian-12) |

更早的版本（9 Stretch 及之前）均已结束官方支持，个别包可通过第三方 ELTS 获取延长更新。

## 升级路线：只能逐版本走

Debian 官方**不支持跨版本升级**。标准路线永远是相邻版本逐步推进：

```text
10 (Buster) → 11 (Bullseye) → 12 (Bookworm) → 13 (Trixie) → 14 (Forky, 发布后)
```

每一步的通用流程（详细命令见[升级指南](/basics/upgrade)）：

1. 完全更新当前版本，备份 `/etc` 与数据
2. 将软件源中的代号切换为目标版本（含 security 源）
3. `apt update && apt full-upgrade`，按提示处理配置文件变化
4. 重启，确认服务与硬件正常，再进入下一步

跨过两个以上版本直接改源升级几乎必然出现依赖残骸——老系统（如 Debian 10）评估后直接重装往往更省时间。

## 支持窗口的模式

每个稳定版的生命周期遵循相同模式（具体日期见 [EOL 页](/eol)）：

1. **stable**：发布后由安全团队全量维护，期间滚动发布点更新
2. **oldstable + 常规安全支持**：下一版发布后约一年，安全更新仍由安全团队负责
3. **LTS**：由 LTS 团队接管约三年，覆盖五个架构
4. **EOL**：官方支持终止，仅剩第三方 ELTS

以 Debian 12 为例：2023-06-10 发布 → 2026-07 常规安全支持结束 → 2028-06-30 LTS 结束。Debian 13 的对应节点是 2028-08 与 2030-06-30。
