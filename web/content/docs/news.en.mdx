## 2026 Updates

### Version Releases

#### Debian 13.7 Planned for 2026-09-12

According to the Debian Release Team's plan, Debian 13.7 is expected on **2026-09-12** (subject to confirmation in the official announcement). It is the seventh point update of Debian 13 (Trixie) and will usually contain security fixes and critical bug fixes.

- [Debian Release Management](https://release.debian.org/)
- [Debian Releases](https://www.debian.org/releases/)

#### Debian 11 (Bullseye) LTS Has Ended (2026-08-31)

Long-Term Support (LTS) for Debian 11 (Bullseye) ended on **August 31, 2026**. Debian no longer provides security updates; a subset of packages is covered by third-party **ELTS** until **2031-06-30**. Systems still running Debian 11 should migrate to Debian 12/13 as soon as possible, or evaluate isolation, ELTS, and retirement.

- [Official Announcement](https://www.debian.org/News/2026/20260831)
- [About Debian LTS](https://wiki.debian.org/LTS)
- [Extended LTS](https://wiki.debian.org/LTS/Extended)
- [Release End-of-Life (EOL)](/en/eol)

#### DebConf26 Closes in Santa Fe, DebConf27 Announced (2026-08-07)

DebConf26 closed on July 25, 2026 in Santa Fe, Argentina. More than 270 attendees from 35 countries took part in 90 events, and the next DebConf27 was announced.

- [Official Announcement](https://www.debian.org/News/2026/20260807)

#### Debian 13.6 and 12.15 Released (2026-07-11)

On 2026-07-11, Debian released two point updates simultaneously:
- **Debian 13.6**: Sixth point update of the current stable release (Trixie), with security fixes and critical bug fixes
- **Debian 12.15**: Routine point update of oldstable (Bookworm), and the final point update within its regular security support period

- [Debian Release Information](https://www.debian.org/releases/)
- [Download Debian 13.6](/en/download)

#### Debian 12 (Bookworm) Has Entered LTS (2026-07-11)

Regular security support for Debian 12 (Bookworm) ended on **July 11, 2026**, and Bookworm has now moved into the **Long-Term Support (LTS)** phase, with security updates handled by the Debian LTS team (volunteers and companies) until **June 30, 2028**.

- Systems still running Debian 12 will continue to receive security updates, but planning an upgrade to Debian 13 (Trixie) is recommended.
- [About Debian LTS](https://wiki.debian.org/LTS)
- [Upgrade to Debian 13 Guide](/en/basics/upgrade)
- [Release End-of-Life (EOL)](/en/eol)

### Cloud & Containers

#### Debian 13 Cloud and Container Images Updated (2026-09-08)

The latest official Debian 13 cloud image build is **20260831-2587** (2026-08-31). It supports AWS EC2, Microsoft Azure, OpenStack, and local QEMU/plain VM use, with `generic`, `genericcloud`, `nocloud`, `ec2`, and `azure` image types. Current AWS AMIs are `debian-13-amd64-20260831-2587` / `debian-13-arm64-20260831-2587`; the Azure image URN is `Debian:debian-13:13:latest`.

- Debian 12 LTS cloud images were refreshed on **2026-09-07**; Debian 11 reached EOL on 2026-08-31 and its cloud images no longer receive Debian security updates.
- Debian 14 (Forky) testing daily cloud images are available for testing, not production.
- The official Docker images `debian:13` / `debian:13-slim` were updated to 13.6 (2026-08-25); pin a point-release tag or digest for production containers.
- Debian 13.7 is planned for 2026-09-12; cloud and Docker images will be rebuilt afterwards.

- [Debian official cloud images](https://cloud.debian.org/images/cloud/)
- [Debian Cloud wiki](https://wiki.debian.org/Cloud)
- [AWS Debian 13 images](https://wiki.debian.org/Cloud/AmazonEC2Image/Trixie)
- [Azure Debian images](https://wiki.debian.org/Cloud/MicrosoftAzure)

### Project Governance

#### General Resolution: LLM Usage in Debian (2026-08-30)

The Debian General Resolution on LLM usage has concluded. The voting period ran from 2026-08-15 to 2026-08-28, and Option 5, **"Responsible Use of Generative AI"**, was the winner.

- [Vote result](https://www.debian.org/vote/2026/vote_002)

The 2026 DPL election has concluded, and **Sruthi Chandran** was elected as the new Debian Project Leader. Her term began on **April 21, 2026**, succeeding two-term DPL Andreas Tille. The sole nominee this year, she won with 289 votes to 50 (None of the above).

### Security Maintenance

The Debian Security Team continues to publish DSA (Debian Security Advisory) and DLA (Debian LTS Advisory) notices. As of 2026-09-08, recent advisories cover firefox-esr, thunderbird, chromium, linux, roundcube, strongswan, jbig2dec, libssh2, pcre2, and others; the latest numbers include DSA-6488-1 (jbig2dec), DSA-6487-1 (strongswan), DSA-6486-1 (libde265), DSA-6484-1 (chromium), DSA-6481-1 (firefox-esr), plus DLA-4776-1 (chromium), DLA-4775-1 (thunderbird), DLA-4774-1 (aom), DLA-4773-1 (libssh2), and DLA-4770-1 (firefox-esr).

- Stable (Debian 13) is maintained by the Security Team
- Debian 12 (Bookworm) moved to LTS team maintenance on 2026-07-11; LTS support for Debian 11 (Bullseye) ended on 2026-08-31 — Debian no longer provides security updates, and a subset of packages is covered by third-party ELTS until 2031-06-30; systems still running it should be migrated or retired promptly
- [Security Advisories](https://www.debian.org/security/)
- [LTS Security Advisories](https://www.debian.org/lts/security/)
