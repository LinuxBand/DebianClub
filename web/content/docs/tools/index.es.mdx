Estas herramientas se ejecutan localmente en el navegador. La interfaz interactiva está disponible por ahora en inglés; esta página explica los límites en español.

<InteractiveTools lang="en" />

## Límites

- Las selecciones no se suben a ningún servidor.
- Los resultados son recomendaciones y no modifican el sistema automáticamente.
- Antes de copiar comandos, revisa el codename de la versión, mirror, componentes, estado del disco y entorno actual.

## Herramientas

| Herramienta | Propósito |
|-------------|-----------|
| Mirror Selector | Generar recomendaciones deb822 para fuentes APT |
| Install Planner | Elegir ruta de instalación según equipo, objetivo y riesgo |
| Desktop Picker | Recomendar GNOME, KDE Plasma o Xfce según hardware y flujo |
| Partition Planner | Sugerir particiones según disco, arranque y cifrado |
| Troubleshooting Wizard | Proponer comprobaciones de solo lectura y rutas de diagnóstico |
| Command Safety Checker | Marcar localmente scripts remotos, borrado recursivo, escrituras de disco, degradación SSH y riesgos de confianza APT |
| AI Skills Installer | Generar comandos locales de instalación y verificación de DebianClub AI Skills |
| Upgrade Planner | Planificar ventana de actualización, riesgo y comprobaciones de solo lectura según versión y exposición |
| Package Search | Búsqueda en vivo en más de 25 repositorios de distribuciones (datos de pkgseek), ver [página dedicada](/es/tools/pkgseek) |
