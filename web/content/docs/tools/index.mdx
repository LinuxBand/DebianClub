Debian 交互工具箱把常见选择题和排障流程做成可点击的工具，帮助你更快得到适合自己的安装、配置和排查路线。

<InteractiveTools lang="zh" />

## 使用边界

- 工具只在浏览器本地运行，不会上传选择结果。
- 输出是建议，不会自动修改系统。
- 复制命令前请确认发行版代号、镜像站、组件范围、磁盘状态和当前系统环境。
- 可以用 hash 直接打开具体工具，例如 `/tools#command-safety`。

## 已上线工具

| 工具 | 作用 |
|------|------|
| 镜像源选择器 | 生成 deb822 sources 建议，并链接到源格式说明 |
| 安装方式选择器 | 根据设备、目标和风险偏好推荐安装路线 |
| 桌面环境选择器 | 根据硬件和工作流推荐 GNOME、KDE Plasma 或 Xfce |
| 分区方案生成器 | 根据磁盘、启动模式和加密偏好生成分区建议 |
| 排障问诊向导 | 给出只读检查命令，并跳转到对应排障页面 |
| 命令安全检查器 | 本地检查远程脚本、递归强删、磁盘写入、SSH 降级和 APT 信任风险 |
| AI Skills 安装命令生成器 | 生成 DebianClub AI Skills 本地安装和验证命令 |
