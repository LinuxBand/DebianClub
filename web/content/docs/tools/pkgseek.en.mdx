Type a package name or keyword to query the official repositories of 25+ distributions indexed by [pkgseek](https://pkgseek.com/).

<PackageSearch lang="en" />

## Usage Notes

- Results highlight the **Debian 13 (trixie)** version; click a package name to open its pkgseek page with all distro versions, dependencies and related CVEs.
- Shareable searches: after searching, the address bar shows `?q=<keyword>` — copy the link to share.
- More online tools: [Error → install command](https://pkgseek.com/doctor), [file reverse-lookup](https://pkgseek.com/files), [version matrix embeds](https://pkgseek.com/embed/packages/nginx).
- For local package management, see the [APT guide](/en/administration/packages).
