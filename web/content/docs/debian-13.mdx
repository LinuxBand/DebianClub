<Callout type="info" title="当前稳定版">

**Debian 13** 代号 **Trixie**，于 **2025 年 8 月 9 日** 正式发布，是当前的 **stable（稳定版）**。截至 2026 年 9 月，最新点更新为 **13.7**（2026-09-12）。本页汇总新特性、下载、安装与支持周期，是新装 Debian 的首选版本。

</Callout>

## 📌 状态速览

| 项目 | 信息 |
|------|------|
| **开发代号** | Trixie（《玩具总动员》中的角色） |
| **发布日期** | 2025-08-09 |
| **当前点更新** | 13.7（2026-09-12） |
| **内核** | Linux 6.12 LTS 系列 |
| **架构** | amd64、arm64、armhf、i386、ppc64el、s390x、**riscv64**（首次官方支持） |

| **LTS 支持** | 至 2030-06-30 |
| **定位** | 新装桌面、服务器、生产环境的默认选择 |

## 🚀 相比 Debian 12 的主要变化

- **内核**：Linux 6.12 LTS 系列（Debian 12 为 6.1 LTS）
- **桌面**：GNOME 48、KDE Plasma 6.3（Debian 12 为 GNOME 43 / Plasma 5.27），Wayland 成为大多数桌面的默认会话
- **工具链**：GCC 14、LLVM 19、Python 3.13、PHP 8.4
- **架构**：riscv64 首次成为官方支持架构，共 7 个架构
- **桌面体验**：`/tmp` 默认挂载为 tmpfs，重启自动清理
- **软件源**：安装器默认写入 deb822 格式的 `.sources` 文件（Debian 12 引入的新格式）
- **固件**：继续使用 `non-free-firmware` 组件（自 Debian 12 起引入），安装器可自动加载常见硬件固件

具体组件版本对照见 [版本与生命周期](/versions)。

## 💾 下载与安装

- 从[系统下载](/download)选择版本、架构和就近镜像站，获取 netinst / DVD / Live 镜像
- 按需制作[启动盘](/basics/bootable-media)，再跟随[安装指南](/basics/installation)完成安装
- 云环境可直接使用 [Debian 官方云镜像](https://cloud.debian.org/images/cloud/)，或用[下载页](/download)选择官方 cdimage
- 装好后的第一步看[首次启动](/basics/first-boot)，系统调优见[系统配置](/basics/configuration)

## 🔄 从 Debian 12 升级

Debian 12（Bookworm）用户可直接按[系统升级指南](/basics/upgrade)升级到 13：先完全更新当前系统，再把软件源切换为 trixie（注意 security 源写法），`apt full-upgrade` 完成后重启验证。升级前务必备份 `/etc` 与数据，并保留一个可用的救援环境。

## 🛡️ 支持周期

- **常规安全支持**：至 **2028-08-09**（由 Debian 安全团队维护）
- **LTS 长期支持**：至 **2030-06-30**（由 LTS 团队维护）
- 下一代 [Debian 14 (Forky)](/debian-14) 正在开发中；按惯例 Trixie 会在 14 发布后继续获得约一年的常规安全支持，再进入 LTS

完整的生命周期与 EOL 日期见[版本支持周期 (EOL)](/eol)。

## ❓ 常见问题

| 问题 | 回答 |
|------|------|
| 该装 13 还是等 14？ | 装 13。14（Forky）还在 testing 阶段，[发布至少要到 2027 年](/debian-14) |
| 13.7 是最新版吗？ | 是。点更新只整合修复，版本号随发布推进，当前为 13.7 |
| 需要 non-free 源吗？ | 固件在 `non-free-firmware` 组件；NVIDIA 驱动等仍需 `non-free`，见[硬件与驱动](/hardware) |
| 支持 riscv64 吗？ | 支持——Debian 13 是首个官方支持 riscv64 的版本 |
| 中文支持怎么样？ | GNOME/KDE 下安装 fcitx5 或 ibus 即可，详见[输入法配置](/applications/input-methods) |
