## 统一排查原则

1. 先识别硬件型号和内核模块，再安装驱动包。
2. 优先使用 Debian 官方仓库和 backports，避免厂商 `.run` 安装器或未知脚本。
3. 每次只改一个变量：firmware、内核、驱动、桌面会话不要同时改。
4. 记录变更前后的命令输出，便于回滚和提问。
5. 图形和网络驱动变更后，保留一个可进 TTY 或有线网络的备用路径。

## 常用识别命令

```bash
lspci -nnk
lsusb
uname -a
apt policy firmware-linux firmware-linux-nonfree nvidia-driver
journalctl -b -p warning
dmesg --level=err,warn
```

如果要分享日志，先删掉主机名、用户名、SSID、MAC 地址、公网 IP、序列号和路径中的个人信息。
