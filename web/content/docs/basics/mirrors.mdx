<Verified date="2026-11-19" label="实测验证">Debian 13.6.0 / TUNA</Verified>


国内访问 `deb.debian.org` 速度很不稳定：实测只有 **15–56 KB/s**，换清华 TUNA 后达到 **25 MB/s**，apt 能快两三个数量级。

Debian 13.6 安装器**默认写入传统一行式** `/etc/apt/sources.list`（`sources.list.d/` 为空）；deb822 的 `.sources` 是 APT 3.0 支持的**可选格式**，适合新配置或需要多 `Suites`/`Signed-By` 的场景。两种写法二选一，不要混用。

## 常用国内镜像

| 镜像站 | 地址 |
|--------|------|
| 清华 TUNA | `https://mirrors.tuna.tsinghua.edu.cn/debian/` |
| 中科大 USTC | `https://mirrors.ustc.edu.cn/debian/` |
| 阿里云 | `https://mirrors.aliyun.com/debian/` |
| 腾讯云 | `https://mirrors.cloud.tencent.com/debian/` |
| 网易 | `https://mirrors.163.com/debian/` |

不确定选哪个时，用我们的[镜像源选择器](/tools#mirror)按所在地自动生成配置。

<Callout type="warn" title="安全源不要忘">

很多人只换了主仓库，漏掉 `trixie-security`，导致安全更新走官方慢速源甚至缺失。换源时务必同时替换下文示例中的 `-security` 一行。

</Callout>

## 方式一：deb822 格式（可选）

编辑 `/etc/apt/sources.list.d/debian.sources`（以清华源为例）：

```text
Types: deb
URIs: https://mirrors.tuna.tsinghua.edu.cn/debian/
Suites: trixie trixie-updates trixie-security
Components: main contrib non-free non-free-firmware
Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg
```

注意：`Suites` 里要同时包含 `trixie`、`trixie-updates` 和 **`trixie-security`**。安全更新通常走镜像站的 `debian-security` 路径，建议像下面传统格式那样单独写一个安全源条目，避免部分镜像站路径不一致。

安装器默认只启用 `main non-free-firmware`；需要 `contrib`/`non-free` 时再自行加上。

## 方式二：传统 sources.list（13.6 安装器默认）

编辑 `/etc/apt/sources.list`，替换为（以中科大为例）：

```text
deb https://mirrors.ustc.edu.cn/debian/ trixie main contrib non-free non-free-firmware
deb https://mirrors.ustc.edu.cn/debian/ trixie-updates main contrib non-free non-free-firmware
deb https://mirrors.ustc.edu.cn/debian/ trixie-security main contrib non-free non-free-firmware
```

如果系统里同时存在 `/etc/apt/sources.list` 和 `/etc/apt/sources.list.d/debian.sources`，把不用的那个改名备份（如加 `.bak` 后缀），否则同一批包会出现双份来源。

## 生效与验证

```bash
sudo apt update
apt policy firefox-esr | head -5
```

![apt update 命中镜像](/images/verify/apt/apt-update-zh.png)

![apt policy 校验镜像](/images/verify/apt/apt-policy-zh.png)

`apt update` 无报错、`apt policy` 显示的候选版本来自镜像站地址，即换源成功。

注意：安装器只替换主仓库，`trixie-security` 默认仍指向 `security.debian.org`；截图里第 3 行就是官方安全源。要全走镜像，需手动改安全源。 `apt update` 出现 404 时优先检查 Suites 拼写和镜像站是否同步完成。

## 常见问题

| 问题 | 原因与处理 |
|------|-----------|
| `404 Not Found` | 镜像站尚未同步完成，或 Suites 写错（trixie 而不是 bookworm） |
| GPG 签名错误 | `Signed-By` 路径写错；Debian 13 的钥匙环在 `/usr/share/keyrings/debian-archive-keyring.gpg` |
| 换源后 update 反而变慢 | 与 DNS 有关，优先用 HTTPS 直连镜像站而非 HTTP 代理 |
| 需要非自由软件 | `Components` 里保留 `contrib non-free non-free-firmware` |
