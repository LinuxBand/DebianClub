<Verified date="2026-11-21" label="Verified">Debian 13.6 / APT 3.0.3</Verified>


Debian 13 (Trixie) is the first stable release with **APT 3.0**. It brings a redesigned command-line output and a new dependency solver; for sources, APT 3.0 **supports both** the classic one-line `sources.list` and deb822 `.sources` files.

## What APT 3.0 Changes

### More Readable Output

`apt update`, `apt upgrade` and friends now use a **column layout** with counts for packages to install, upgrade and remove:

```bash
sudo apt update
sudo apt upgrade
```

![apt update on Debian 13.6](/images/verify/apt/apt-update-en.png)

### New Dependency Solver

APT 3.0 rewrote dependency resolution so complex conflicts produce saner plans and fewer "remove half the system" proposals.

## What the Installer Actually Writes

A common claim is that "Debian 13 installs deb822 `debian.sources` by default". **That is not what 13.6 does.**

After a Debian 13.6.0 netinst install, the installer writes the classic one-line `/etc/apt/sources.list`; `/etc/apt/sources.list.d/` is empty:

```bash
# /etc/apt/sources.list (actual output from Debian 13.6)
deb cdrom:[Debian GNU/Linux 13.6.0 _Trixie_ - Official amd64 NETINST ...]/ trixie contrib main non-free-firmware

deb http://deb.debian.org/debian/ trixie main non-free-firmware
deb-src http://deb.debian.org/debian/ trixie main non-free-firmware

deb http://security.debian.org/debian-security trixie-security main non-free-firmware
deb-src http://security.debian.org/debian-security trixie-security main non-free-firmware

deb http://deb.debian.org/debian/ trixie-updates main non-free-firmware
deb-src http://deb.debian.org/debian/ trixie-updates main non-free-firmware
```

Three details:

- **No `trixie-backports` by default**; add it manually if needed.
- Default components are only `main` and `non-free-firmware`, not `contrib`/`non-free`.
- `deb-src` lines are written too (source repositories are enabled by default).

<Callout type="info" title="Verified environment">

Debian 13.6.0 amd64 netinst (2026-07-11 build), PVE 9.2.2 + OVMF, mirror set to `deb.debian.org` during install. The mirror host varies, but the **format is one-line**.

</Callout>

## deb822 Format (Optional)

deb822 writes each source as multi-line `Key: value` blocks. It is clearer for multiple `Suites`, `Components` or `Signed-By`, and APT 3.0 fully supports it, but it is **optional**, not the installer default:

```yaml
# /etc/apt/sources.list.d/debian.sources
Types: deb
URIs: https://deb.debian.org/debian
Suites: trixie trixie-updates
Components: main non-free-firmware
Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg
```

Security updates usually live in a separate file:

```yaml
Types: deb
URIs: https://security.debian.org/debian-security
Suites: trixie-security
Components: main non-free-firmware
Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg
```

<Callout type="warn" title="Do not mix both formats for the same source">

`/etc/apt/sources.list` and `sources.list.d/*.sources` are read together. When migrating, back up and remove the old file, or `apt update` will see duplicate sources.

</Callout>

## Inspect and Adjust Sources

```bash
# List active sources (APT 3.0: use apt-get indextargets)
apt-get indextargets | grep -E '^(Repo-URI|Suite|Component):' | sort -u

# Refresh indexes after changes
sudo apt update
```

`apt indextargets` is not a valid subcommand in APT 3.0 and fails with `Invalid operation indextargets`; use `apt-get indextargets`.

![apt-get indextargets on Debian 13.6](/images/verify/apt/indextargets-en.png)

The measured `Suite` values are `stable`, `stable-security`, and `stable-updates` (aliases, not `trixie`); components are only `main` and `non-free-firmware`.
