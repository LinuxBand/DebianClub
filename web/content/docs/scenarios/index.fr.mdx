Les scénarios Debian regroupent installation, configuration, sécurité et maintenance dans des parcours prêts à suivre. Les pages détaillées existent actuellement en chinois et en anglais; cette page sert d’entrée en français.

## Scénarios disponibles

| Scénario | Usage principal | Détail |
|----------|-----------------|--------|
| Docker Host | Services conteneurisés sur un hôte Debian stable | [Anglais](/en/scenarios/docker-host) |
| Development Workstation | Utiliser Debian comme poste de développement quotidien | [Anglais](/en/scenarios/development-workstation) |
| Home Server | Héberger des services sur un mini-PC ou une machine réutilisée | [Anglais](/en/scenarios/home-server) |
| NAS / File Sharing | Fichiers, sauvegardes et partages sur le réseau local | [Anglais](/en/scenarios/nas-file-sharing) |
| Local AI Inference Machine | Modèles locaux, GPU et services d’inférence | [Anglais](/en/scenarios/local-ai-inference) |
| Ops Jump Box | Accès SSH centralisé, audit et diagnostic | [Anglais](/en/scenarios/ops-jump-box) |

## Choisir un parcours

- Pour une base serveur, commencez par [Home Server](/en/scenarios/home-server).
- Pour les conteneurs, utilisez [Docker Host](/en/scenarios/docker-host).
- Pour le stockage partagé, ouvrez [NAS / File Sharing](/en/scenarios/nas-file-sharing).
- Pour l’IA locale, combinez [Local AI Inference Machine](/en/scenarios/local-ai-inference) avec [Matériel et pilotes](/fr/hardware).
