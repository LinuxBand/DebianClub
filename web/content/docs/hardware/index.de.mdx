## Diagnoseprinzipien

1. Geräte-ID und Kernelmodul zuerst prüfen.
2. Debian-Repositories und Backports gegenüber unbekannten Installationsskripten bevorzugen.
3. Firmware, Kernel, Treiber und Desktop-Sitzung nicht gleichzeitig ändern.
4. Ausgaben vor und nach Änderungen speichern.
5. Bei Grafik- und Netzwerkänderungen immer einen Fallback wie TTY oder Ethernet behalten.

## Häufige Befehle

```bash
lspci -nnk
lsusb
uname -a
journalctl -b -p warning
dmesg --level=err,warn
```
