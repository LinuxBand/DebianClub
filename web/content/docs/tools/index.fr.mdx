## Limites

- Les choix ne sont pas envoyés à un serveur.
- Les résultats sont des recommandations et ne modifient jamais le système automatiquement.
- Avant de copier une commande, vérifiez le nom de version, le miroir, les composants, l’état du disque et l’environnement courant.

## Outils

| Outil | Objectif |
|-------|----------|
| Mirror Selector | Générer des recommandations deb822 pour APT |
| Install Planner | Choisir un parcours d’installation selon la machine, l’objectif et le risque |
| Desktop Picker | Recommander GNOME, KDE Plasma ou Xfce selon le matériel et le flux de travail |
| Partition Planner | Suggérer un partitionnement selon le disque, le mode de démarrage et le chiffrement |
| Troubleshooting Wizard | Fournir des vérifications en lecture seule et des pistes de diagnostic |
| Command Safety Checker | Signaler localement scripts distants, suppressions récursives, écritures disque, baisse de sécurité SSH et risques APT |
| AI Skills Installer | Générer les commandes locales d’installation et de validation des DebianClub AI Skills |
| Upgrade Planner | Planifier la fenêtre de mise à niveau, les risques et les vérifications en lecture seule selon la version et l’exposition |
