Cette page résume les contrôles minimum avant de publier une nouvelle version de DebianClub.

## Portes de publication

| Contrôle | Objectif |
|----------|----------|
| Type check | MDX, types de routes et TypeScript passent |
| Production build | L’export statique Next.js est généré complètement |
| Search index | Les index par langue existent sous `/api/search/{locale}` |
| Key pages | Accueil, scénarios, matériel, versions, outils et déploiement chargent |
| Static assets | Headers, sitemap, robots.txt, images et `skills.json` existent |

## Commandes locales

```bash
. "$HOME/.nvm/nvm.sh"
corepack pnpm --dir web types:check
corepack pnpm --dir web build
corepack pnpm --dir web release:check
```

## Avant déploiement

- Vérifier que les index de recherche restent sous la limite Cloudflare Pages.
- Les nouveaux contenus ne doivent pas envoyer de scripts distants directement dans un shell.
- Les outils peuvent recommander des actions, mais ne doivent pas modifier le système automatiquement.
- En cas d’échec, revenir d’abord au dernier export statique valide.
