Debian 시나리오는 설치, 설정, 보안, 유지보수 문서를 실제 배포 흐름으로 묶습니다. 자세한 문서는 현재 중국어와 영어로 제공되며, 이 페이지는 한국어 사용자를 위한 입구입니다.

## 제공 중인 시나리오

| 시나리오 | 적합한 용도 | 상세 문서 |
|----------|-------------|-----------|
| Docker Host | 안정적인 Debian 위에서 컨테이너 서비스 운영 | [영어](/en/scenarios/docker-host) |
| Development Workstation | Debian을 주 개발 환경으로 사용 | [영어](/en/scenarios/development-workstation) |
| Home Server | 미니 PC나 재활용 PC에서 서비스 실행 | [영어](/en/scenarios/home-server) |
| NAS / File Sharing | LAN 파일 공유, 백업, 공동 폴더 | [영어](/en/scenarios/nas-file-sharing) |
| Local AI Inference Machine | 로컬 모델, GPU, 추론 서비스 | [영어](/en/scenarios/local-ai-inference) |
| Ops Jump Box | 중앙 SSH 진입점, 감사, 진단 | [영어](/en/scenarios/ops-jump-box) |

## 선택 기준

- 서버 기본기는 [Home Server](/en/scenarios/home-server)에서 시작합니다.
- 컨테이너는 [Docker Host](/en/scenarios/docker-host)를 봅니다.
- 공유 스토리지는 [NAS / File Sharing](/en/scenarios/nas-file-sharing)을 사용합니다.
- 로컬 AI는 [Local AI Inference Machine](/en/scenarios/local-ai-inference)과 [하드웨어와 드라이버](/ko/hardware)를 함께 확인합니다.
