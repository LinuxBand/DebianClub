Os cenários Debian transformam guias separados de instalação, configuração, segurança e manutenção em caminhos completos de implantação. As páginas detalhadas estão disponíveis por enquanto em chinês e inglês; esta página é a entrada em português.

## Cenários disponíveis

| Cenário | Melhor para | Detalhe |
|---------|-------------|---------|
| Docker Host | Serviços em contêiner sobre um Debian estável | [Inglês](/en/scenarios/docker-host) |
| Development Workstation | Usar Debian como ambiente diário de desenvolvimento | [Inglês](/en/scenarios/development-workstation) |
| Home Server | Executar serviços em um mini PC ou computador reutilizado | [Inglês](/en/scenarios/home-server) |
| NAS / File Sharing | Arquivos, backups e pastas compartilhadas na LAN | [Inglês](/en/scenarios/nas-file-sharing) |
| Local AI Inference Machine | Modelos locais, GPU e serviços de inferência | [Inglês](/en/scenarios/local-ai-inference) |
| Ops Jump Box | Acesso SSH centralizado, auditoria e diagnóstico | [Inglês](/en/scenarios/ops-jump-box) |

## Como escolher

- Para base de servidor, comece por [Home Server](/en/scenarios/home-server).
- Para contêineres, use [Docker Host](/en/scenarios/docker-host).
- Para armazenamento compartilhado, abra [NAS / File Sharing](/en/scenarios/nas-file-sharing).
- Para IA local, combine [Local AI Inference Machine](/en/scenarios/local-ai-inference) com [Hardware e drivers](/pt/hardware).
