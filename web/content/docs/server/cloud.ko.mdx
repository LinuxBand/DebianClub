## 지원 클라우드 환경

| 플랫폼 | 지원 | 비고 |
|--------|------|------|
| Amazon EC2 | 공식 | amd64/arm64, Debian 공식 AMI |
| Microsoft Azure | 공식 | amd64, Azure Marketplace |
| OpenStack | 공식 | `generic` 이미지를 Glance에 업로드 |
| 일반 VM / QEMU | 공식 | `nocloud` 또는 `generic` |
| Google Compute Engine | 서드파티 | Google이 구축, Debian 공식 이미지 아님 |

## 이미지 유형

| 유형 | 용도 | cloud-init |
|------|------|------------|
| `generic` | 범용, 대부분의 클라우드와 로컬 가상화 지원 | 예 |
| `genericcloud` | generic과 유사하나 하드웨어 드라이버 축소 | 예 |
| `nocloud` | cloud-init을 실행하지 않고 root로 직접 부팅 | 아니요 |
| `ec2` | Amazon EC2에 최적화 | 예 |
| `azure` | Microsoft Azure에 최적화 | 예 |

기본 사용자는 대부분 `debian`, AWS EC2는 `admin`입니다. SSH 키는 cloud-init으로 주입하고 비밀번호 로그인은 비활성화하세요.

## 빠른 시작

```bash
wget https://cloud.debian.org/images/cloud/trixie/latest/debian-13-generic-amd64.qcow2
wget https://cloud.debian.org/images/cloud/trixie/latest/SHA512SUMS
sha512sum -c SHA512SUMS --ignore-missing
```

- AWS: AMI `debian-13-amd64-20260831-2587` / `debian-13-arm64-20260831-2587`
- Azure: URN `Debian:debian-13:13:latest`
- OpenStack: `generic` 이미지 업로드
- 로컬: `nocloud` 이미지를 QEMU로 부팅
