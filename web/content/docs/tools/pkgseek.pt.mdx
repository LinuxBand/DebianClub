## Notas de uso

- Os resultados destacam a versão do **Debian 13 (trixie)**; clique no nome do pacote para abrir sua página no pkgseek com todas as versões, dependências e CVEs.
- Buscas compartilháveis: após a busca, a barra de endereço mostra `?q=<palavra>` — copie o link para compartilhar.
- Mais ferramentas online: [Erro → comando de instalação](https://pkgseek.com/doctor), [busca reversa de arquivos](https://pkgseek.com/files), [matrizes de versões incorporadas](https://pkgseek.com/embed/packages/nginx).
- Gerenciamento local de pacotes: [guia APT](/pt/administration/packages).
