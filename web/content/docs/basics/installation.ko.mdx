## 설치 프로그램 시작

### BIOS/UEFI 설정 접근

일반적인 키:
- **Dell**: F2 또는 F12
- **HP**: F10 또는 F9
- **Lenovo**: F1 또는 F12
- **ASUS**: F2 또는 Del

### 설치 단계

1. **언어 선택** — 한국어 또는 선호 언어
2. **네트워크 구성** — 유선 연결 권장
3. **디스크 파티션** — 초보자는 가이드 파티션 사용
4. **기본 시스템 설치** — 자동 다운로드
5. **소프트웨어 선택** — 기본 흐름에서는 묻지 않고 데스크톱 + GNOME + 표준 도구를 자동 설치합니다. 선택 화면은 전문가 모드에서만 나옵니다.
6. **GRUB 부트로더 설치** — UEFI에서는 질문 없이 EFI 파티션에 설치됩니다.
7. **설치 완료** — 재시작

## 권장 파티션 레이아웃

| 파티션 | 크기 | 파일 시스템 | 비고 |
|-------|-----|-----------|------|
| `/boot/efi` | 512MB | FAT32 | UEFI 시스템만 |
| `/` | 20-50GB | ext4 | 루트 파티션 |
| `swap` | 2-8GB | swap | 가상 메모리 |
| `/home` | 나머지 공간 | ext4 | 사용자 데이터 |

실측: 17.2 GB 디스크와 2 GiB RAM에서 EFI 925.9 MB, swap 899.7 MB가 생성되었습니다. 표의 크기는 수동 파티션 권장값입니다.

## 13.6에서 확인한 내용

- **부팅 메뉴:** UEFI는 5개 항목이며 **`Help`가 없습니다**. `Help`는 BIOS 메뉴에만 있습니다.
- **파티션:** 17.2 GB 디스크와 2 GiB RAM에서 EFI 925.9 MB, 루트 15.4 GB, swap 899.7 MB가 생성됩니다(“RAM과 동일”이 아님).
- **소프트웨어 선택:** 기본 흐름에서도 45개 기본 패키지 후에 이 목록이 나타나며 데스크톱 + GNOME + 표준 도구가 미리 선택되어 있습니다. 계속을 누르면 됩니다.
- **SSH:** `openssh-server`는 기본 선택이 아니며, 새로 설치한 시스템에는 sshd가 없습니다.
- **GRUB:** UEFI에서는 MBR을 묻지 않고 EFI 파티션에 설치됩니다.
- **시간대:** 영어 설치에서는 질문하지만, 중국어 + 중국은 자동으로 `Asia/Shanghai`를 사용합니다.
- **미러:** `deb.debian.org`는 15–56 KB/s였고, `mirrors.tuna.tsinghua.edu.cn`은 25 MB/s였습니다.
