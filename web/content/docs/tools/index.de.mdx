Diese Werkzeuge laufen lokal im Browser. Die Oberfläche des Werkzeugs ist derzeit auf Englisch verfügbar, während diese Seite die Nutzung auf Deutsch einordnet.

<InteractiveTools lang="en" />

## Grenzen

- Auswahlen werden nicht hochgeladen.
- Ergebnisse sind Empfehlungen und ändern das System nicht automatisch.
- Prüfen Sie vor dem Kopieren von Befehlen Release-Codename, Spiegelserver, Komponenten, Datenträgerstatus und aktuelle Systemumgebung.

## Werkzeuge

| Werkzeug | Zweck |
|----------|-------|
| Mirror Selector | deb822-Quellenempfehlungen erzeugen |
| Install Planner | Installationspfad nach Gerät, Ziel und Risikoprofil wählen |
| Desktop Picker | GNOME, KDE Plasma oder Xfce nach Hardware und Workflow empfehlen |
| Partition Planner | Partitionslayout nach Datenträger, Bootmodus und Verschlüsselung vorschlagen |
| Troubleshooting Wizard | Nur-lesende Prüfungen und passende Diagnosepfade ausgeben |
| Command Safety Checker | Remote-Skripte, rekursives Löschen, Datenträgerzugriffe, SSH-Absenkung und APT-Vertrauensrisiken lokal markieren |
| AI Skills Installer | Lokale Installations- und Prüfkommandos für DebianClub AI Skills erzeugen |
