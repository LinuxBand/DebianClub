## Princípios de diagnóstico

1. Identifique primeiro o dispositivo e o módulo do kernel.
2. Prefira repositórios Debian e backports a scripts desconhecidos.
3. Não mude firmware, kernel, driver e sessão gráfica ao mesmo tempo.
4. Guarde saídas antes e depois das mudanças.
5. Mantenha uma rota de recuperação como TTY ou Ethernet.

## Comandos úteis

```bash
lspci -nnk
lsusb
uname -a
journalctl -b -p warning
dmesg --level=err,warn
```
