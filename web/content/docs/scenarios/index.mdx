Debian 场景方案把分散的安装、配置、安全和维护教程组织成可落地的路线。每个方案都会说明适用人群、推荐硬件、安装方式、必装软件包、安全配置、备份策略和常见问题。

## 已上线场景

| 方案 | 适合谁 | 当前状态 |
|------|----------|----------|
| [Docker 主机](/scenarios/docker-host) | 需要稳定容器运行环境的开发者和运维 | 已上线 |
| [开发工作站](/scenarios/development-workstation) | 把 Debian 作为主力开发环境的用户 | 已上线 |
| [家用服务器](/scenarios/home-server) | 希望用旧电脑或迷你主机运行服务的用户 | 已上线 |
| [NAS / 文件共享](/scenarios/nas-file-sharing) | 希望集中管理照片、文档和备份的家庭或小团队 | 已上线 |
| [本地 AI 推理机器](/scenarios/local-ai-inference) | 想在本地运行模型和推理服务的用户 | 已上线 |
| [运维跳板机](/scenarios/ops-jump-box) | 需要集中 SSH、审计和故障诊断入口的团队 | 已上线 |

## 使用建议

先选择最接近你目标的场景页，再进入对应的专题文档。场景页负责给出路线，专题页负责展开具体命令和配置细节。
