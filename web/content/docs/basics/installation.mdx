本教程按 **Debian 13.6.0 amd64 netinst** 的真实安装流程编写，截图来自 PVE 9.2.2 上的 UEFI 虚拟机（OVMF，2 vCPU / 2 GiB / 16 GiB）。实体机界面基本一致，差异会在对应位置注明。

<Callout type="info" title="实测环境">

- 介质：`debian-13.8.0-amd64-netinst.iso`（当前点版本；本文截图使用 13.6.0，安装流程一致）
- 固件：UEFI（OVMF）；BIOS 对照见下一节
- 镜像：`mirrors.tuna.tsinghua.edu.cn`（国内实测 25 MB/s）
- 安装日期：2026-11-18 / 19

</Callout>

## 🎯 安装前准备

### 确认清单

- ✅ **启动盘已制作完成**
- ✅ **重要数据已备份**
- ✅ **网络连接可用**（推荐，netinst 需要联网装桌面）
- ✅ **电源连接稳定**（笔记本用户）
- ✅ **至少 30 分钟空闲时间**（国内镜像 + 桌面约 10–15 分钟）

### 安装方式选择

| 安装方式 | 适用场景 | 优势 | 注意事项 |
|----------|----------|------|----------|
| **全新安装** | 新电脑或完全替换系统 | 系统最干净 | 会擦除所有数据 |
| **双系统安装** | 保留现有 Windows | 可以切换系统 | 需要调整分区 |
| **虚拟机安装** | 学习和测试 | 安全无风险 | 性能有所降低 |

<Callout type="warn" title="⚠️ 重要提醒">

全新安装会**完全擦除**硬盘数据！请务必备份重要文件。

</Callout>

## 💿 启动安装程序

### 1. 设置 BIOS/UEFI

常见按键：

- **Dell**: <span class="kbd">F2</span> 或 <span class="kbd">F12</span>
- **HP**: <span class="kbd">F10</span> 或 <span class="kbd">F9</span>
- **Lenovo**: <span class="kbd">F1</span> 或 <span class="kbd">F12</span>
- **ASUS**: <span class="kbd">F2</span> 或 <span class="kbd">Del</span>
- **MSI**: <span class="kbd">Del</span> 或 <span class="kbd">F11</span>

把 USB 设为第一启动项；如果安装程序无法启动，再尝试关闭 Secure Boot。

### 2. 启动菜单：UEFI 和 BIOS 不一样

**UEFI 模式**（13.6 实测）只有 5 项，**没有 Help**：

```text
Debian GNU/Linux 13.6.0
Debian GNU/Linux UEFI Installer menu

Graphical install
Install
Advanced options ...
Accessible dark contrast installer menu ..
Install with speech synthesis
```

![UEFI 启动菜单](/images/verify/uefi-boot-menu.png)

**BIOS/Legacy 模式**才有 `Help`，标题也不同：

```text
Debian GNU/Linux installer menu (BIOS mode)

Graphical install
Install
Advanced options ...
Accessible dark contrast installer menu ..
Help
Install with speech synthesis
```

![BIOS 启动菜单](/images/verify/bios-boot-menu.png)

网上不少教程把这两种菜单混写成一份，看到“有 Help”就知道那是 BIOS 菜单。

#### 选择安装方式

- **Graphical install** - 图形界面安装（推荐）
- **Install** - 文本界面安装

<Callout type="warn" title="图形安装不一定总是图形界面">

在部分虚拟机/固件组合下（实测 SeaBIOS + std VGA），选择 `Graphical install` 会回退到文本安装界面。实体机通常正常；如果进入文本界面，按提示继续即可，功能一致。

</Callout>

## 🌍 语言和区域设置

### 1. 选择语言

选择 **中文（简体）** 或 **English**。语言列表里中文在 `Chinese (Simplified)` 一行。

### 2. 选择位置

选择“中国”。这一步决定时区和默认镜像列表。

### 3. 配置键盘

中文用户选“汉语”，英文用户选“American English”。

<Callout type="info" title="英文流程会多一步时区">

选择中文 + 中国时，安装器自动使用 `Asia/Shanghai`，不询问时区；选择 English + United States 时会多出 “Configure the clock / Select your time zone” 一步。文档旧版完全没提这一点。

</Callout>

## 🌐 网络与镜像

### 自动网络配置

有线网络通常 DHCP 自动完成。如果第一次 DHCP 失败，安装器会给出“重试网络自动配置 / 不配置网络”的选项，选重试通常即可。

### 配置网络镜像

安装器会先问“扫描额外的安装介质？”，选“否”，然后进入镜像选择：

1. 国家选“中国”
2. 主机列表里选国内镜像

![安装器里的镜像国家列表](/images/verify/installation/mirror-list-zh.png)

![选择清华 TUNA 镜像](/images/verify/mirror-tuna.png)

**国内强烈建议选国内镜像**。实测从国内访问 `deb.debian.org` 只有 **15–56 KB/s**，装桌面会卡在下载；换 `mirrors.tuna.tsinghua.edu.cn` 后达到 **25 MB/s**，桌面任务约 5 分钟装完。

| 镜像 | 地址 |
|------|------|
| 清华 TUNA | `mirrors.tuna.tsinghua.edu.cn` |
| 中科大 | `mirrors.ustc.edu.cn` |
| 阿里云 | `mirrors.aliyun.com`（安装器列表里没有，适合装完后手动换源） |

## 👤 用户和密码设置

### 1. 设置 root 密码

root 是系统管理员账户。安装器**不会强制**密码强度：实测输入 `debian` 直接通过，没有弱密码警告。

密码建议：至少 12 位，包含大小写字母、数字、特殊字符，避免生日、姓名等。

### 2. 创建普通用户

```text
全名：张三               # 显示名称
用户名：zhangsan         # 登录名称（小写字母）
密码：************       # 用户密码
```

<Callout type="info" title="💡 用户名建议">

- 使用小写字母和数字
- 避免特殊字符
- 建议使用拼音或英文

</Callout>

## 💾 磁盘分区

<DiskPartition />

这是安装过程中最重要的步骤。

### 分区方式菜单（实测文案）

实际菜单是“向导 - …”，不是旧文档里的“使用整个磁盘并设置 LVM”：

![分区方式](/images/verify/installation/partition-method-zh.png)

```text
向导 - 使用最大的连续空闲空间
向导 - 使用整个磁盘
向导 - 使用整个磁盘并配置 LVM
向导 - 使用整个磁盘并配置加密的 LVM
手动
```

**新手选“向导 - 使用整个磁盘”**，下一步选磁盘，再选“将所有文件放在同一个分区中（推荐新手使用）”。

### 向导默认分出来多大？

以 17.2 GB 磁盘、2 GiB 内存为例，实测结果：

![分区总览](/images/verify/installation/partition-overview-zh.png)

| 分区 | 实测大小 | 说明 |
|------|----------|------|
| EFI 系统分区 | 925.9 MB | FAT32，挂载 `/boot/efi` |
| 根分区 `/` | 15.4 GB | ext4 |
| swap | 899.7 MB | 约等于内存的 44%，**不是**“等于内存大小” |

旧文档说 swap 要“等于内存大小（4–8 GB）”、EFI 要 512 MB，和向导默认结果并不一致。想自定义大小，选“手动”：

| 挂载点 | 建议大小 | 文件系统 | 说明 |
|--------|----------|----------|------|
| `/boot/efi` | 512 MB–1 GB | FAT32 | UEFI 启动分区 |
| `/` | 25–50 GB | ext4 | 根分区 |
| `/home` | 剩余空间 | ext4 | 用户数据（可选） |
| `swap` | 4–8 GB 或等于内存 | swap | 休眠需要 ≥ 内存 |

### 手动分区

选“手动”后进入分区表视图，可以逐块调整：

![手动分区总览](/images/verify/installation/manual-partition-overview-zh.png)

选中空闲空间后可“创建新分区”，先输入大小：

![新建分区大小](/images/verify/installation/manual-partition-size-zh.png)

### 写入确认

分区总览页确认无误后，选择“完成分区操作并将修改写入磁盘”，确认页默认是“否”，需要手动选“是”：

![写入确认](/images/verify/installation/partition-write-confirm-zh.png)

## 📦 软件选择：默认流程也会出现清单

基础包下载完成（进度条走完 45 个文件）后，安装器会弹出“软件选择”清单，**默认已经勾选**：

- `Debian 桌面环境`
- `... GNOME`
- `标准系统工具`

![默认流程的软件选择](/images/verify/software-selection-default-zh.png)

直接点“继续”就按默认任务安装；想换桌面，取消 GNOME，勾选 Xfce / KDE Plasma 等即可。

从 **Advanced options → 图形专家安装** 进入时是同一张清单，只是会多问一些低优先级问题：

![专家模式的软件选择](/images/verify/software-selection-expert.png)

实际条目（13.6）：

```text
☑ Debian 桌面环境
☑ ... GNOME
☐ ... Xfce
☐ ... GNOME Flashback
☐ ... KDE Plasma
☐ ... Cinnamon
☐ ... MATE
☐ ... LXDE
☐ ... LXQt
☐ web server
☐ SSH server
☑ 标准系统工具
☐ Choose a Debian Blend for installation
```

注意：

- 文档旧版漏了 **GNOME Flashback**、**LXQt**、**Debian Blend**；
- **SSH server 默认不勾选**，装完系统默认没有 sshd；
- 需要 SSH 的，在清单里勾选，或装完后 `sudo apt install openssh-server`。

### 桌面环境对比

| 桌面环境 | 资源占用 | 特点 | 适合用户 |
|----------|----------|------|----------|
| **GNOME** | 高 | 现代化，触控友好 | 新手，现代设计爱好者 |
| **KDE Plasma** | 中高 | 高度可定制，功能丰富 | 喜欢自定义的用户 |
| **Xfce** | 低 | 传统界面，稳定 | 老机器，传统桌面用户 |
| **LXDE / LXQt** | 很低 | 极简轻量 | 低配置机器 |

## ⚡ 安装过程与耗时

进度页会依次显示：安装基本系统 → 配置 apt → 选择并安装软件 → 安装 GRUB → 完成。

实测耗时（国内镜像）：

| 阶段 | 耗时 |
|------|------|
| 分区 + 基本系统 | 约 3–5 分钟 |
| 桌面任务（GNOME + 标准工具） | 约 5 分钟（tuna，25 MB/s） |
| **合计** | **约 10–15 分钟** |

如果镜像选的是 `deb.debian.org` 且在国内，下载可能只有几十 KB/s，桌面任务会拖到几小时——这不是 netinst 的限制，是镜像选择问题。

## 🔧 引导程序

UEFI 安装不会问“是否安装到主引导记录”，GRUB 会直接装到 EFI 分区；GRUB 2.12 的菜单实测为：

![GRUB 菜单](/images/verify/grub-menu.png)

```text
GNU GRUB 2.12-9+deb13u2 版
Debian GNU/Linux
Advanced options for Debian GNU/Linux
UEFI Firmware Settings
```

默认 5 秒后自动启动。BIOS 模式才会出现“安装到主引导记录”的确认。

## 🔧 安装后基本配置

### 1. 更新系统

```bash
sudo apt update
sudo apt upgrade -y
```

### 2. SSH server（默认未安装）

默认任务不勾选 SSH server，装完后 `sshd` 不存在：

![装 SSH 前：sshd 未安装](/images/verify/ssh/sshd-absent-zh.png)

需要时再装：

```bash
sudo apt install openssh-server
sudo systemctl enable --now ssh
```

![装 SSH 后：22 端口监听](/images/verify/ssh/sshd-active-zh.png)

### 3. 安装常用软件

```bash
sudo apt install curl wget git vim
sudo apt install ffmpeg
sudo apt install fonts-noto-cjk
```

### 4. 中文输入法

```bash
sudo apt install ibus ibus-pinyin
ibus-setup
```

### 5. 浏览器和办公软件

```bash
sudo apt install firefox-esr
sudo apt install libreoffice libreoffice-l10n-zh-cn
```

## 🆘 常见安装问题

### 无法启动到安装程序

1. 检查 BIOS 启动顺序
2. 尝试关闭 Secure Boot
3. 换一个 USB 端口
4. 重新制作启动盘

### 卡在下载软件包

国内最常见原因就是镜像选成了 `deb.debian.org`。返回镜像选择（或装完后换源）改用清华/中科大/阿里云。

### 没有 sshd

默认不安装 SSH server：

```bash
sudo apt install openssh-server
sudo systemctl enable --now ssh
```

### GRUB 安装失败

1. 确认 UEFI/BIOS 模式与启动盘一致
2. 检查 EFI 分区是否存在
3. 关闭 Secure Boot 后重试
