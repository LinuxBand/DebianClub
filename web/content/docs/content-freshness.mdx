内容时效校验用于标记会随时间变化的页面，避免版本、生命周期、包支持窗口和发布流程长期停留在旧口径。

## Phase 44 已上线

发布门禁现在包含：

```bash
corepack pnpm --dir web freshness:check
```

该检查读取仓库中的时效基线，确认关键页面仍包含当前复核日期、官方来源链接和必须同步的生命周期日期。

## 更新流程

1. 先查官方来源，不从摘要站点复制生命周期日期。
2. 更新页面里的复核日期和具体日期。
3. 同步 `web/_migration/content-freshness-check.mjs` 的基线。
4. 运行 `corepack pnpm --dir web freshness:check`。
5. 再运行完整 `corepack pnpm --dir web release:check`。

## 失效处理

如果 `freshness:check` 失败，不要直接放宽检查。先判断：

- 是否到了下一次强制复核日期。
- Debian 官方是否更新了生命周期或 release note。
- 页面是否缺少官方来源链接。
- 中英文页面是否只更新了一边。
