Estas ferramentas rodam localmente no navegador. A interface interativa está disponível por enquanto em inglês; esta página descreve os limites em português.

<InteractiveTools lang="en" />

## Limites

- As escolhas não são enviadas a nenhum servidor.
- Os resultados são recomendações e não modificam o sistema automaticamente.
- Antes de copiar comandos, revise codename da versão, mirror, componentes, estado do disco e ambiente atual.

## Ferramentas

| Ferramenta | Propósito |
|------------|-----------|
| Mirror Selector | Gerar recomendações deb822 para fontes APT |
| Install Planner | Escolher caminho de instalação por dispositivo, objetivo e risco |
| Desktop Picker | Recomendar GNOME, KDE Plasma ou Xfce conforme hardware e fluxo |
| Partition Planner | Sugerir partições conforme disco, boot e criptografia |
| Troubleshooting Wizard | Fornecer checagens somente leitura e rotas de diagnóstico |
| Command Safety Checker | Sinalizar localmente scripts remotos, remoção recursiva, escritas em disco, rebaixamento SSH e riscos de confiança APT |
| AI Skills Installer | Gerar comandos locais de instalação e validação dos DebianClub AI Skills |
| Upgrade Planner | Planejar janela de atualização, risco e checagens somente leitura por versão e exposição |
| Package Search | Busca em tempo real em mais de 25 repositórios de distribuições (dados do pkgseek), ver [página dedicada](/pt/tools/pkgseek) |
