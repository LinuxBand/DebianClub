Los escenarios Debian convierten guías separadas de instalación, configuración, seguridad y mantenimiento en rutas completas de despliegue. Las páginas detalladas están disponibles por ahora en chino e inglés; esta página ofrece una entrada en español.

## Escenarios disponibles

| Escenario | Mejor para | Detalle |
|-----------|------------|---------|
| Docker Host | Servicios de contenedores sobre un Debian estable | [Inglés](/en/scenarios/docker-host) |
| Development Workstation | Usar Debian como entorno diario de desarrollo | [Inglés](/en/scenarios/development-workstation) |
| Home Server | Ejecutar servicios en un mini PC o equipo reutilizado | [Inglés](/en/scenarios/home-server) |
| NAS / File Sharing | Archivos, copias de seguridad y carpetas compartidas en LAN | [Inglés](/en/scenarios/nas-file-sharing) |
| Local AI Inference Machine | Modelos locales, GPU y servicios de inferencia | [Inglés](/en/scenarios/local-ai-inference) |
| Ops Jump Box | Acceso SSH centralizado, auditoría y diagnóstico | [Inglés](/en/scenarios/ops-jump-box) |

## Cómo elegir

- Para una base de servidor, empieza por [Home Server](/en/scenarios/home-server).
- Para contenedores, usa [Docker Host](/en/scenarios/docker-host).
- Para archivos y backups, abre [NAS / File Sharing](/en/scenarios/nas-file-sharing).
- Para modelos locales, combina [Local AI Inference Machine](/en/scenarios/local-ai-inference) con [Hardware y controladores](/es/hardware).
