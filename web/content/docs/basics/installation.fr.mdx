## Préparation avant l'installation

- ✅ Support de démarrage créé
- ✅ Données importantes sauvegardées
- ✅ Connexion réseau disponible (recommandée)

- **Support :** `debian-13.8.0-amd64-netinst.iso` (version ponctuelle actuelle ; les captures de ce guide proviennent de 13.6.0).

<Callout type="warn" title="Important">

L'installation fraîche **effacera complètement** les données du disque dur ! Sauvegardez vos fichiers importants.

</Callout>

## Démarrage de l'installateur

### Accéder aux paramètres BIOS/UEFI

Touches communes :
- **Dell** : F2 ou F12
- **HP** : F10 ou F9
- **Lenovo** : F1 ou F12
- **ASUS** : F2 ou Del

### Étapes d'installation

1. **Sélectionner la langue** — Français ou votre langue préférée
2. **Configurer le réseau** — Connexion filaire recommandée
3. **Partitionner le disque** — Utiliser le partitionnement guidé pour les débutants
4. **Installer le système de base** — Téléchargement automatique
5. **Sélectionner les logiciels** — Le parcours standard ne demande rien : il installe bureau + GNOME + utilitaires ; la liste n’apparaît qu’en installation experte.
6. **Installer le chargeur d'amorçage GRUB** — En UEFI, GRUB est installé dans la partition EFI sans question.
7. **Terminer l'installation** — Redémarrer

## Partitionnement recommandé

| Partition | Taille | Système de fichiers | Notes |
|-----------|--------|---------------------|-------|
| `/boot/efi` | 512 Mo | FAT32 | Systèmes UEFI uniquement |
| `/` | 20-50 Go | ext4 | Partition racine |
| `swap` | 2-8 Go | swap | Mémoire virtuelle |
| `/home` | Espace restant | ext4 | Données utilisateur |

Mesuré : avec un disque de 17,2 Go et 2 Gio de RAM, l’assistant crée une EFI de 925,9 Mo et un swap de 899,7 Mo. Les tailles du tableau sont une recommandation pour un partitionnement manuel.

## Résolution des problèmes courants

```bash
# Vérifier si le démarrage UEFI est activé
ls /sys/firmware/efi

# Réinstaller GRUB si nécessaire
sudo grub-install /dev/sda
sudo update-grub
```

## Détails vérifiés en 13.6

- **Menu de démarrage :** l’UEFI a cinq entrées et **pas de `Help`** ; `Help` n’existe que dans le menu BIOS.
- **Partitionnement :** avec un disque de 17,2 Go et 2 Gio de RAM, l’assistant crée EFI 925,9 Mo, racine 15,4 Go et swap 899,7 Mo (pas « égal à la RAM »).
- **Sélection des logiciels :** le parcours standard affiche aussi la liste (après les 45 paquets de base), avec bureau + GNOME + utilitaires déjà cochés ; cliquez simplement sur Continuer.
- **SSH :** `openssh-server` n’est pas présélectionné ; une installation fraîche n’a pas de sshd.
- **GRUB :** en UEFI, GRUB est installé dans la partition EFI sans question sur le MBR.
- **Fuseau horaire :** les installations en anglais le demandent ; chinois + Chine utilise automatiquement `Asia/Shanghai`.
- **Miroirs :** `deb.debian.org` ne donnait que 15–56 Ko/s ; `mirrors.tuna.tsinghua.edu.cn` atteignait 25 Mo/s.
