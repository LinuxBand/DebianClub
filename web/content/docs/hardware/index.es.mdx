## Principios de diagnóstico

1. Identifica primero el dispositivo y el módulo del kernel.
2. Prefiere repositorios Debian y backports frente a scripts desconocidos.
3. No cambies firmware, kernel, controlador y sesión gráfica al mismo tiempo.
4. Guarda salidas antes y después de cada cambio.
5. Mantén una vía de recuperación como TTY o Ethernet.

## Comandos útiles

```bash
lspci -nnk
lsusb
uname -a
journalctl -b -p warning
dmesg --level=err,warn
```
