Debian-Szenarien verbinden Installation, Konfiguration, Sicherheit und Wartung zu umsetzbaren Pfaden. Die vollständigen Detailseiten sind derzeit auf Chinesisch und Englisch verfügbar; diese Seite führt deutschsprachige Leser zu den wichtigsten Einstiegspunkten.

## Verfügbare Szenarien

| Szenario | Geeignet für | Detailseite |
|----------|--------------|-------------|
| Docker Host | Container-Dienste auf einem stabilen Debian-System | [Englisch](/en/scenarios/docker-host) |
| Development Workstation | Debian als tägliche Entwicklungsumgebung | [Englisch](/en/scenarios/development-workstation) |
| Home Server | Dienste auf einem Mini-PC oder alten Rechner | [Englisch](/en/scenarios/home-server) |
| NAS / File Sharing | Dateien, Backups und gemeinsame Ordner im LAN | [Englisch](/en/scenarios/nas-file-sharing) |
| Local AI Inference Machine | Lokale Modelle, GPU-Treiber und Inferenzdienste | [Englisch](/en/scenarios/local-ai-inference) |
| Ops Jump Box | Zentraler SSH-Zugang, Audit und Diagnose | [Englisch](/en/scenarios/ops-jump-box) |

## Auswahlhilfe

- Für Servergrundlagen zuerst [Home Server](/en/scenarios/home-server) lesen.
- Für Container-Stacks mit [Docker Host](/en/scenarios/docker-host) beginnen.
- Für gemeinsame Dateien und Backups [NAS / File Sharing](/en/scenarios/nas-file-sharing) verwenden.
- Für lokale Modelle [Local AI Inference Machine](/en/scenarios/local-ai-inference) mit [Hardware & Drivers](/de/hardware) kombinieren.
