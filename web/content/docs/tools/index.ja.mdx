これらのツールはブラウザー内でローカルに動作します。インタラクティブ UI は現在英語ですが、このページでは日本語で利用上の注意をまとめます。

<InteractiveTools lang="en" />

## 境界

- 選択内容はアップロードされません。
- 出力は提案であり、システムを自動変更しません。
- コマンドをコピーする前に、リリースコード名、ミラー、コンポーネント、ディスク状態、現在の環境を確認してください。

## ツール

| ツール | 目的 |
|--------|------|
| Mirror Selector | deb822 形式の APT ソース案を生成 |
| Install Planner | デバイス、目的、リスク許容度からインストール経路を選ぶ |
| Desktop Picker | ハードウェアと作業内容から GNOME、KDE Plasma、Xfce を推薦 |
| Partition Planner | ディスク、起動方式、暗号化に応じたパーティション案を出す |
| Troubleshooting Wizard | 読み取り専用の確認コマンドと診断先を提示 |
| Command Safety Checker | リモートスクリプト、再帰削除、ディスク書き込み、SSH 設定低下、APT 信頼リスクをローカルで検出 |
| AI Skills Installer | DebianClub AI Skills のローカルインストールと検証コマンドを生成 |
