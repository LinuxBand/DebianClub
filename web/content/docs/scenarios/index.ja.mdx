Debian シナリオは、インストール、設定、セキュリティ、保守の手順を実運用向けの流れにまとめたものです。詳細ページは現在、中国語と英語で提供しています。このページは日本語の入口です。

## 利用できるシナリオ

| シナリオ | 主な用途 | 詳細 |
|----------|----------|------|
| Docker Host | 安定した Debian 上でコンテナサービスを動かす | [英語](/en/scenarios/docker-host) |
| Development Workstation | Debian を日常の開発環境にする | [英語](/en/scenarios/development-workstation) |
| Home Server | ミニ PC や再利用した PC でサービスを動かす | [英語](/en/scenarios/home-server) |
| NAS / File Sharing | LAN 内のファイル共有、バックアップ、共有フォルダ | [英語](/en/scenarios/nas-file-sharing) |
| Local AI Inference Machine | ローカルモデル、GPU、推論サービス | [英語](/en/scenarios/local-ai-inference) |
| Ops Jump Box | SSH の集中入口、監査、診断 | [英語](/en/scenarios/ops-jump-box) |

## 選び方

- サーバーの土台は [Home Server](/en/scenarios/home-server) から始めます。
- コンテナ用途は [Docker Host](/en/scenarios/docker-host) を使います。
- 共有ストレージは [NAS / File Sharing](/en/scenarios/nas-file-sharing) を参照します。
- ローカル AI は [Local AI Inference Machine](/en/scenarios/local-ai-inference) と [ハードウェアとドライバー](/ja/hardware) を組み合わせます。
